# Wan2GP в Google Colab — русская версия

[![Открыть в Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/GamidKambulatov05/wan2gp-colab-ru/blob/main/wan2gp-colab-ru.ipynb)

**Это русская версия установочного ноутбука и интерфейса Wan2GP**, сделанная мной для тех, кто не хочет разбираться в англоязычной документации.

- **Нужен русский?** — используй этот репозиторий: ноутбук с русскими шагами и русский слой интерфейса (перевод вкладок, кнопок, режимов "текст→видео / картинка→видео / продолжить видео").
- **Нужен оригинал на английском без перевода?** — вот официальные репозитории, разбирайся сам:
  - генератор: [deepbeepmeep/Wan2GP](https://github.com/deepbeepmeep/Wan2GP)
  - установка в Colab, на основе которой сделан этот ноутбук: [Square-Zero-Labs/Wan2GP-on-Colab](https://github.com/Square-Zero-Labs/Wan2GP-on-Colab)

Готовый ноутбук Google Colab для запуска [Wan2GP](https://github.com/deepbeepmeep/Wan2GP) — универсального open-source инструмента для генерации видео, изображений и озвучки (в том числе на модели Wan 2.1/2.2) с веб-интерфейсом Gradio.

Все шаги, комментарии и сообщения переведены на русский язык — просто открывай ноутбук в Colab и жми ячейки по порядку сверху вниз.

## Быстрый старт

1. Жми кнопку **"Открыть в Colab"** вверху этого README — ноутбук откроется сразу в Google Colab.
2. `Runtime → Change runtime type` → выбери **GPU**.
3. Выполняй ячейки по порядку (Шаг 1 → Шаг 6).
4. В выводе последней ячейки появится ссылка на интерфейс — открой её в браузере.

## Почему так, а не просто `pip install`

Прямая установка через обычный `pip install` из официального репозитория Wan2.1 запускает сборку `flash-attn` из исходников — на Colab это может занимать **1.5-2+ часа** практически без прогресса в выводе. Этот ноутбук вместо этого:

- использует `uv` вместо pip (значительно быстрее разрешает и ставит зависимости);
- переиспользует уже установленный в Colab PyTorch вместо принудительной переустановки;
- не требует сборки flash-attn из исходников;
- сразу поднимает Gradio-интерфейс с публичной ссылкой (`--share`), без ручной настройки.

## Одна рекомендуемая модель вместо выбора (Шаг 6)

По умолчанию (`LOCK_TO_RECOMMENDED_MODEL = True` в ячейке Шага 6) интерфейс запускается с флагами `--t2v --lock-model` — это встроенный режим самого WanGP, который **полностью скрывает выбор семейства/версии модели, фильтры и тулбар**. Остаётся только название модели (Wan2.1 Text-to-Video 14B), поле промпта и кнопка "Сгенерировать" — никакой лишней панели с кнопками. Если позже захочешь сам переключаться между моделями — поставь `LOCK_TO_RECOMMENDED_MODEL = False` и перезапусти ячейку.

## Русский интерфейс (Шаг 5в)

Отдельный необязательный шаг добавляет поверх интерфейса WanGP:

- перевод всех 7 вкладок и **более 200 подписей, кнопок и технических параметров** — от базовых (Применить/Сохранить/Сгенерировать) до продвинутых (Guidance Phases, Sampler Solver/Scheduler, LoRA-множители, параметры маскирования, аудио-синхронизация и т.д.);
- подсказки у фильтра моделей — что значит "All/Movie/Image/Audio" (наведи курсор на иконки);
- зелёную плашку прямо над режимами "Новое видео / Продолжить видео / Продолжить последнее видео" с объяснением, **куда нажать, чтобы сделать видео из текста, из картинки или продолжить готовое видео** — это самый частый вопрос новичков;
- лёгкий рестайлинг в духе тёмных тем ChatGPT/Claude.

Работает через собственный слой CSS/JS (`shared/gradio/ui_styles.css` и `ui_scripts.js`), не патчит сам код WanGP — переживает `git pull`.

**Что сознательно не переведено:** маркетинговые описания самих моделей (абзацы вида "The original Wan Text 2 Video model…") — это не интерфейс, а контент-описания моделей, хранятся отдельно от кода интерфейса и обновляются авторами WanGP независимо.

## Ограничения бесплатного тарифа Colab

Бесплатный GPU (обычно T4, 15 ГБ) не тянет большинство моделей Wan2GP в полном размере. Рабочий вариант на бесплатном тарифе — модель **Wan 2.2 TextImage2Video FastWan**, ~5 секунд видео в 480p за ~8 минут. На платной подписке (Colab Pro, GPU A100 40-80 ГБ) доступны полноразмерные модели вплоть до 720p.
